# zellij/

Zellij terminal multiplexer config.

| File                 | Purpose                                                 |
| -------------------- | ------------------------------------------------------- |
| `config.kdl`         | Keybindings, plugins, options; sets `default_layout`    |
| `layouts/wayout.kdl` | The default layout: even-column / even-row swap layouts |

`programs.zellij.enable = true` (in `home.nix`) installs Zellij but does **not**
manage these files — they are edited directly here, not generated by Nix.

## Even-column grid

`wayout.kdl` lays panes out as **up to 4 even-width columns** by default. Panes
1–4 each open a new column; pane 5+ stack as new rows _within_ columns, filling
left-to-right, so every column keeps the same width — no full-width or
double-width panes.

```
1..4 = one row of N columns
5 = [2,1,1,1]   6 = [2,2,1,1]   7 = [2,2,2,1]   8 = [2,2,2,2]
9 = [3,2,2,2]  10 = [3,3,2,2]  11 = [3,3,3,2]  12 = [3,3,3,3]
```

(`[a,b,c,d]` = panes stacked in each of the 4 columns.) Each pane count has its
own `exact_panes=N` variant, so Zellij auto-rebalances into the grid whenever a
pane is added or removed.

| Keys              | Action                                                      |
| ----------------- | ----------------------------------------------------------- |
| `Alt n`           | New pane — auto-rebalances into the grid                    |
| `Alt e`           | Re-even now (after a manual split/resize broke the spacing) |
| `Alt ]` / `Alt [` | Toggle grid ↔ even rows                                     |

Use plain `Alt n` for auto-even. The directional `NewPane` bindings (pane-mode
`r` / `d`) manually split the focused pane and bypass the layout — hit `Alt e`
afterward to snap back to even.

## Supporting more panes / changing the cap

The grid currently covers up to 12 panes (4 columns of 3). To go higher, copy
the last `ui exact_panes=12 { ... }` block in the `columns` swap layout, bump
the number, and add the extra pane to the shortest column (left-to-right). Each
of the 4 columns is a `pane { ... }` holding its stacked panes, and the very
last cell of the grid is the only `pane { children; }`. To change the 4-column
cap, add or remove a column in every variant. Verify with `zellij setup --check`
(must report `Well defined.`).

The full step-by-step recipe is kept as a comment above the `columns` layout in
`wayout.kdl`, right where you'll be editing.

## Changes take effect in new sessions

Already-running sessions keep their current layout. Start a fresh Zellij session
to pick up changes to `default_layout` or the layout file.
