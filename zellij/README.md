# zellij/

Zellij terminal multiplexer config.

| File                            | Purpose                                                 |
| ------------------------------- | ------------------------------------------------------- |
| `config.kdl`                    | Keybindings, plugins, options; sets `default_layout` and `theme` |
| `layouts/wayout.kdl`            | The default layout: row-major grid / even-column swap layouts |
| `themes/archeofuturism.kdl`     | Chrome colors, sharing the Pi theme's palette           |

`programs.zellij.enable = true` (in `home.nix`) installs Zellij but does **not**
manage these files — they are edited directly here, not generated by Nix.

## Row-major grid

`wayout.kdl` lays panes out as a **row-major grid, up to 4 columns per row**, by
default. Panes fill a row left-to-right until it holds 4 columns, then a new
even-height row starts below. Each row splits its own width evenly across
however many panes it holds, and all rows share height evenly.

```
1..4 = one row of N even columns
5 = [4,1]   6 = [4,2]   7 = [4,3]   8 = [4,4]
9 = [4,4,1]  10 = [4,4,2]  11 = [4,4,3]  12 = [4,4,4]
```

(`[a,b,…]` = columns per row, top to bottom.) Each pane count has its own
`exact_panes=N` variant, so Zellij auto-rebalances into the grid whenever a pane
is added or removed.

| Keys              | Action                                                      |
| ----------------- | ----------------------------------------------------------- |
| `Alt n`           | New pane — Zellij auto-applies the matching grid variant    |
| `Alt e`           | Re-even now (after a manual split/resize broke the spacing) |
| `Alt ]` / `Alt [` | Toggle grid ↔ even columns                                  |

Use plain `Alt n` for auto-even; pane-mode `n` performs the same reflow. The
directional `NewPane` bindings (pane-mode `r` / `d`) manually split the focused
pane and bypass the layout — hit `Alt e` afterward to snap back to even.

## Supporting more panes / changing the cap

The grid currently covers up to 12 panes (3 rows of 4). To go higher, copy the
last `ui exact_panes=12 { ... }` block in the `grid` swap layout, bump the
number, and add the extra pane to the last (bottom) row — starting a new row
once the last row holds 4 columns. Each row is a `pane split_direction="vertical"`
holding its columns, and every terminal cell is a plain `pane`. The `children`
insertion point belongs only in the `ui` tab template. To change the 4-column
cap, change where rows wrap in every variant. Verify with
`nu zellij/layouts.test.nu`.

The full step-by-step recipe is kept as a comment above the `grid` layout in
`wayout.kdl`, right where you'll be editing.

## Theme

`config.kdl` selects `theme "archeofuturism"`, defined in
`themes/archeofuturism.kdl` and sharing its palette with the Pi theme at
`ai/pi/themes/archeofuturism.json`.

Two things about the format are worth knowing before editing it, because both
have already caused visible breakage:

- **`background` is the fill; `base` is the text or line.** Zellij's own
  defaults are `ribbon_selected { base=BLACK background=GREEN }`, which renders
  as the familiar green pill with dark text. Reversing them turns the top and
  bottom bars into glare. The docs do not spell this out.
- **A selected theme with no definition file fails silently.** Zellij falls back
  to its built-in default — whose grey ribbon fill looks white — and
  `zellij setup --check` still reports `CONFIG FILE: Well defined`. Deleting the
  theme file is therefore a visual regression with no error anywhere.

`ai/test/zellij-theme.test.ts` covers both: the selected theme must have a
definition, every fill must stay dark, and pane frames must not turn neon.

### Going back to stock chrome

Comment out the three `theme` lines in `config.kdl` and start a new session.
Nothing else depends on the theme. The pre-theme chrome is also reachable in
git history at `043ff1d` and earlier.

## Changes take effect in new sessions

Already-running sessions keep their current layout **and theme**. Zellij reads
both at session start, so editing these files does nothing to a session that is
already attached — start a fresh Zellij session to see them.
